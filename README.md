# AI-auto-pages 发电站

根地址页面，发布后地址是 `https://ai-auto-pages.github.io/`。

## 页面结构

三张卡片，卡片头是标题，卡片主体是内容：

- 说明
- 选择项目
- 常见问题

页面底部有一行声明。除上面这些内容外，页面不展示其他提示信息。

## 数据来源

页面运行时直接读取本仓库里的 JSON：

- `data/site.json`

JSON 结构已经简化，只保留三项：

```json
{
  "title": "页面标题",
  "products": [
    { "name": "项目名", "url": "项目链接", "price": 1, "tips": "提示区 HTML" }
  ],
  "faqs": [
    { "问题": "蓝奏云打不开？", "回答": "回答 HTML" }
  ]
}
```

主页下拉框显示项目名，选中后详情区显示提示区内容，按钮直接打开项目链接；常见问题卡片按 JSON 里的 `faqs` 列表渲染，每个问题是一个可折叠项，回答按 HTML 渲染。以后维护时只改这个文件，重新发布后刷新页面即可生效。旧的 `data/admin.json`、`data/projects.json` 和 `admin.html` 已经从仓库里删除。

## 样式与编辑页

主页和编辑页使用 Bulma 1.0.4（CDN）加自定义主题 `bulma-theme.css`，字体用 Bulma 默认字体，不再用苹果字体优先。卡片、按钮、下拉、表单、按钮组等都用 Bulma 自带组件：卡片用 `card` / `card-header` / `card-content`，按钮用 `button`，下拉用 `select is-fullwidth`，表单用 `field` / `label` / `control` / `input` / `textarea`，序号控件用 `field has-addons`，上下移删除用 `buttons are-small`，状态提示用 `notification`。卡头保留了旧样式的视觉效果：渐变背景、标题前的青绿到金色装饰条（`card-header::before`）和标题后的渐变细线（`card-header::after`），都写在主题文件里。旧的 `style.css` 不再被页面加载，仅留在仓库里备用。

编辑页地址是 `https://ai-auto-pages.github.io/edit.html`，不从主页链接过去。编辑页没有页头标题和说明，直接是卡片，布局紧凑。基本设置卡片只改标题；项目列表里每个项目都是单独一张卡片，没有项目编号标题，卡片里依次是名称、链接、价格、提示区，提示区下方有一个与主页详情区完全一致的预览框。常见问题在项目列表下方单独一节，每个问题也是一张卡片，依次是问题、回答，回答可填 HTML，下方有预览，卡片右上角有上移、下移、删除，新增常见问题按钮在该节下方。

编辑页是一个纯静态页面，没有自己的服务器：打开后先用本站的静态文件显示当前 JSON。每个项目卡片左上角有序号输入框和确定按钮，右边是上移、下移、删除，序号从 1 开始，最上面就是 1，输入序号点确定即可直接排到该位置；上移、下移和新增都会保留当前页面顺序。保存时才需要令牌，令牌输入框就在最下方的提交按钮前面，提示语只有“令牌”两个字，点保存后页面先用接口拿最新版本和 SHA，比对后提交新 JSON。令牌不写进代码，只在本次打开的页面里使用，也不发给除 GitHub 接口之外的任何地方。提交成功后等 Pages 重新部署几分钟，主页就会更新。

## PC 一屏

PC 端外层用 100vh 高度的弹性布局，标题、三张卡片和底部声明之间按空间分布，内容不再挤在顶部，底部也不会留一大片空白，初始状态刚好铺满一屏。选项目后详情区有内部高度上限，超出时在详情区内滚动。

移动端按正常流式布局滚动，不强制一屏。
