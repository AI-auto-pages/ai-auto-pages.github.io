# AI-auto-pages 发电站

根地址页面，发布后地址是 `https://ai-auto-pages.github.io/`。

## 页面结构

三张卡片，卡片头是标题，卡片主体是内容：

- 说明
- 选择项目
- 常见问题

页面底部有一行声明。除上面这些内容外，页面不展示其他提示信息。

## 数据来源

页面运行时直接读取本仓库里的 JSON：

- `data/site.json`

JSON 结构已经简化，只保留两项：

```json
{
  "title": "页面标题",
  "products": [
    { "name": "项目名", "url": "项目链接", "price": 1, "tips": "提示区 HTML" }
  ]
}
```

主页下拉框显示项目名，选中后详情区显示提示区内容，按钮直接打开项目链接。以后维护时只改这个文件，重新发布后刷新页面即可生效。旧的 `data/admin.json`、`data/projects.json` 不再被页面使用，旧的 `admin.html` 也已被替换为不存在提示页，如需从仓库文件列表里彻底删除旧文件，可在 GitHub 网页上手动删除。

## 样式与编辑页

主页和编辑页共用同一个 `style.css`，卡片、字体、颜色完全统一，全部使用苹果字体。

编辑页地址是 `https://ai-auto-pages.github.io/edit.html`，不从主页链接过去。编辑页没有页头标题和说明，直接是卡片，布局紧凑。基本设置卡片只改标题；项目列表里每个项目都是单独一张卡片，没有项目编号标题，卡片里依次是名称、链接、价格、提示区，提示区下方有一个与主页详情区完全一致的预览框。

编辑页是一个纯静态页面，没有自己的服务器：打开后先用本站的静态文件显示当前 JSON。保存时才需要令牌，令牌输入框就在最下方的提交按钮前面，提示语只有“令牌”两个字，点保存后页面先用接口拿最新版本和 SHA，比对后提交新 JSON。令牌不写进代码，只在本次打开的页面里使用，也不发给除 GitHub 接口之外的任何地方。提交成功后等 Pages 重新部署几分钟，主页就会更新。

## PC 一屏

PC 端外层用 100vh 高度的弹性布局，标题、三张卡片和底部声明之间按空间分布，内容不再挤在顶部，底部也不会留一大片空白，初始状态刚好铺满一屏。选项目后详情区有内部高度上限，超出时在详情区内滚动。

移动端按正常流式布局滚动，不强制一屏。
