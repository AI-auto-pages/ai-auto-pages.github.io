# AI-auto-pages 发电站

根地址页面，发布后地址是 `https://ai-auto-pages.github.io/`。

## 页面结构

三张卡片，卡片头是标题，卡片主体是内容：

- 说明
- 选择项目
- 常见问题

页面底部有一行声明。除上面这些内容外，页面不展示其他提示信息。

## 数据来源

页面不再请求另一个仓库的接口，而是直接读取本仓库里的 JSON：

- `data/admin.json`

这是从原维护仓库复制过来的同一份 JSON，结构和字段不变。页面读取后按原逻辑处理每个产品：解析产品链接里的 sku、生成订单号和支付链接，选中项目后显示该项目的提示内容。

以后维护 JSON 时直接改本仓库的 `data/admin.json`，重新发布后刷新页面即可生效。旧的 `data/projects.json` 不再被页面使用。

## PC 一屏

PC 端外层用 100vh 高度的弹性布局，标题、三张卡片和底部声明之间按空间分布，内容不再挤在顶部，底部也不会留一大片空白，初始状态刚好铺满一屏。选项目后详情区有内部高度上限，超出时在详情区内滚动。

移动端按正常流式布局滚动，不强制一屏。
