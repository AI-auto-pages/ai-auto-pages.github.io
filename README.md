# AI-auto-pages 发电站

根地址页面，发布后地址是 `https://ai-auto-pages.github.io/`。

## 页面结构

三张卡片，卡片头是标题，卡片主体是内容：

- 说明
- 选择项目
- 常见问题

页面底部有一行声明。除上面这些内容外，页面不展示其他提示信息。

## 数据来源

页面运行时从 GitHub API 拉取维护仓库里的同一个 JSON，不在本仓库里维护项目数据：

- 主数据：`repos/blog-auto/json/contents/users/admin.json?ref=main`

流程与原 Angular 代码一致：先试相对代理路径，再走直连 GitHub API，并加时间戳防缓存；返回的 Base64 内容经 UTF-8 解码后解析；对每个产品按原逻辑处理 sku、订单号和支付链接。

维护 JSON 时直接改 `blog-auto/json` 仓库里的文件，刷新本页即可生效。

## PC 一屏

PC 端通过紧凑的卡片间距、标题字号和内边距控制高度，在常见桌面浏览器视口高度下，初始状态（未展开详情、常见问题未展开）刚好一屏展示完，不出现垂直滚动条。选项目后展开的详情区有内部高度上限，超出时在详情区内滚动，页面本身仍尽量保持一屏。

移动端不强制一屏，按正常流式布局滚动。
