# AI-auto-pages 发电站

根地址页面，发布后地址是 `https://ai-auto-pages.github.io/`。

## 页面结构

三张卡片，卡片头是标题，卡片主体是内容：

- 说明
- 选择项目
- 常见问题

页面底部有一行声明。除上面这些内容外，页面不展示其他提示信息。

## 数据来源

页面运行时直接读取本仓库里的 JSON：

- `data/site.json`

JSON 结构已经简化，只保留两项：

```json
{
  "title": "页面标题",
  "products": [
    { "name": "项目名", "url": "项目链接", "price": 1, "tips": "提示区 HTML" }
  ]
}
```

主页下拉框显示项目名，选中后详情区显示提示区内容，按钮直接打开项目链接。以后维护时只改这个文件，重新发布后刷新页面即可生效。旧的 `data/admin.json`、`data/projects.json` 不再被页面使用，旧的 `admin.html` 也已被替换为不存在提示页，如需从仓库文件列表里彻底删除旧文件，可在 GitHub 网页上手动删除。

## 编辑页

编辑页地址是 `https://ai-auto-pages.github.io/edit.html`，不从主页链接过去，只把地址告诉管理员。

它是一个纯静态页面，没有自己的服务器：打开后先用本站的静态文件显示当前 JSON，编辑标题和项目列表（新增、删除、上移、下移、下载备份），每个项目的提示区下方都有一个预览框，样式和主页详情区完全一致，改 HTML 时可以直接看到主页上的效果。

保存时才需要令牌，令牌输入框就在最下方的提交按钮前面：填写细粒度令牌（只选本仓库，Contents 读写权限），点保存后页面先用接口拿最新版本和 SHA，比对你加载时的版本，如果仓库里已经变了会先提示确认，避免覆盖别人刚提交的内容，确认后提交新 JSON。令牌不写进代码，只在本次打开的页面里使用，也不发给除 GitHub 接口之外的任何地方。提交成功后等 Pages 重新部署几分钟，主页就会更新。

## PC 一屏

PC 端外层用 100vh 高度的弹性布局，标题、三张卡片和底部声明之间按空间分布，内容不再挤在顶部，底部也不会留一大片空白，初始状态刚好铺满一屏。选项目后详情区有内部高度上限，超出时在详情区内滚动。

移动端按正常流式布局滚动，不强制一屏。
